# XploreVietnam website (xplorevietnam.org)

Static site. `python3 build.py` assembles `src/pages/*.html` + `src/partials/` into `dist/`.
Hosted on Vercel as its own project (root directory `website`, build `python3 build.py`, output `dist`).
The Navigator app in the repo root is a separate Vercel project (navigator.xplorevietnam.org).
